# Stage 3W — Advanced Squad Tactics

Adds advanced in-battle squad orders on top of Stage 3V formations and Tactical AI.

## Features
- Focus attack on a selected zombie target
- Cover/protect a selected hero
- Flanking orders
- Rescue orders for wounded heroes
- Hold / advance / retreat orders
- Automatic target selection when no explicit target is supplied
- Wounded-backline protection behavior
- Formation switching during combat
- Persistent order/history state
- Advanced tactics HUD panel
- Compatible with existing Stage 3V squad formations and Stage 3U tactical AI
