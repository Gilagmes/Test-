## 🎮 Ключевые игровые механики

### 🏰 1. Полноценная 3D WebGL База и Колония
* Стилизованное 3D-окружение с динамическим суточным циклом (День / Закат / Ночь), мягкими тенями и свободной камерой.
* Живые агенты колонии (инженеры, медики, носильщики, часовые), передвигающиеся по реальным маршрутам между зданиями.
* 10 ключевых зданий: **Ратуша (Штаб)**, **Ферма**, **Лесопилка**, **Мастерская**, **Склад**, **Казарма**, **Госпиталь**, **Лаборатория**, **Рынок**, **Сторожевая вышка**.
* Свободный режим планировки и перемещения зданий по сетке базы.

### 🛡️ 2. Интерактивная Оборона Базы (Tower Defense)
* Тактический режим отражения орд ходячих в реальном времени.
* Полноэкранная арена со шкалой здоровья ворот (`wHP / wMax`) и стрелками гарнизона на частоколе.
* **4 активных ультимейта Командира:**
  * **🔥 Коктейль Молотова:** создает 5-секундную стену огня, замедляющую врагов на 50% и наносящую урон пламенем.
  * **🎯 Снайперский залп:** бронебойный сверхточный выстрел по боссам-мутантам.
  * **⚡ Электро-сетка:** защитный разряд тока, оглушающий переднюю линию орды на 3.5 секунды.
  * **📢 Боевой клич:** адреналиновый раж, удваивающий скорость атаки всех стрелков.

### ⚔️ 3. Классы Армии, Казарма Т1–Т4 и Госпиталь
* **Тактический треугольник преимуществ:**
  * 🗡️ **Защитники (Melee)** ➔ бьют ➔ 🏍️ **Всадников (Cavalry)** ➔ бьют ➔ 🏹 **Стрелков (Marksmen)** ➔ бьют ➔ 🗡️ **Защитников**.
* **4 тира войск (Т1–Т4):**
  * *Т1:* Ополченцы-Ножевики / Стрелки с луками / Разведчики на байках.
  * *Т2:* Мачетеносцы Заставы / Карабинеры Патруля / Рейдеры Пустошей.
  * *Т3:* Щитоносцы «Апекс» / Снайперы-Ликвидаторы / Штурмовые Мотоциклисты.
  * *Т4:* Джаггернауты Цитадели / Пулеметчики «Апекс» / Броне-Кавалеристы.
* **Госпиталь Цитадели:** система учета раненых бойцов с возможностью перевязки и мгновенного возвращения в строй за Провиант.

### 🔗 4. Архетипы Героев и Узы Выживших (Hero Bonds)
* **3 специализации:**
  * ⚔️ *Боевой Профиль:* усиливает армию и урон на стене.
  * 🏗️ *Профиль Развития:* ускоряет стройку и снижает затраты на науку.
  * 📦 *Профиль Снабжения:* ускоряет добычу дерева и еды, увеличивает грузоподъемность.
* **5 легендарных парных уз (Bonds):** «Братья по оружию», «Инженерный рубеж», «Ночной дозор», «Караван снабжения», «Штурмовой авангард» с прокачкой сыгранности (1–5 Ур.).

### 📻 5. Интерактивный Сканер SOS-Сигналов (Radio Radar)
* Осциллограф реального времени с визуализацией радиоволны и звуком помех.
* Точная настройка частоты (88.0 – 108.0 MHz) для перехвата сигналов бедствия, военных конвоев и секретных тайников лаборатории «Апекс».

### 🌲 6. 3D-Расчистка завалов и рассеивание тумана
* 6 расширяемых секторов базы (Разбитые авто, Мертвый лес, Логово ходячих, Портовый кран, Склад мутагена, Подстанция).
* Отправка рабочих с анимациями расчистки, щедрыми трофеями (`🪵`, `⚙`, `💎`) и ростом территории.

### 🗺️ 7. Глобальная Карта ТВД и Альянсы
* Огромная карта Пустошей: марши отрядов, святилища, клановые форпосты, захват ресурсных шахт и совместные рейды.

## 🚀 Быстрый запуск

### Вариант 1: Запуск в 1 клик (без установки)
Просто откройте файл **`index.html`** или **`The_Last_Port_3D_Final.html`** в любом современном веб-браузере (Chrome, Firefox, Safari, Edge). Игра на 100% автономна и работает без интернета!

### Вариант 2: Локальный веб-сервер
```bash
# Клонировать репозиторий
git clone https://github.com/your-username/the-last-port-3d.git
cd the-last-port-3d

# Запустить статический сервер
npx serve .
# или через Python:
python3 -m http.server 8080
```
Откройте в браузере: `http://localhost:8080`

### Вариант 3: Деплой на GitHub Pages
1. Перейдите в **Settings** ➔ **Pages** вашего репозитория.
2. В качестве Source выберите ветку `main` (или `master`) и папку `/ (root)`.
3. Нажмите **Save**. Игра станет доступна по адресу `https://<ваш-логин>.github.io/the-last-port-3d/`!

## 🧪 Запуск автоматических тестов

В проекте реализовано 29 автоматических тестовых наборов, покрывающих всю игровую логику:

```bash
# Запустить все 29 тестов
python3 -c "
import subprocess, os
test_files = [f for f in os.listdir('expedition3d') if f.startswith('test_') and f.endswith('.js')]
for tf in sorted(test_files):
    res = subprocess.run(['node', os.path.join('expedition3d', tf)], capture_output=True)
    print(f'✓ {tf}: PASS' if res.returncode == 0 else f'✗ {tf}: FAIL')
"
```
