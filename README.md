Клон механики Tiles Survival с интеграцией Telegram Web App и голосовым чатом клана (WebRTC).

![Game Preview](https://via.placeholder.com/800x400/1a1a2e/e94560?text=Tiles+Survival+Preview)

## ✨ Особенности

- 🎭 **Уникальные герои**: Выживший, Сталкер, Медик, Мутант
- 🗺️ **Процедурная карта**: Генерация леса, ресурсов и врагов
- 🎤 **Голосовой чат клана**: WebRTC с низкой задержкой
- 📱 **Telegram Integration**: Haptic feedback, нативные кнопки
- 🎨 **Pixel Art стиль**: Ретро-эстетика с современными эффектами
- ⚡ **PWA Ready**: Работает офлайн, устанавливается на телефон
